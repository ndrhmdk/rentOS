## Contract and interval semantics

Inclusive user DATE endpoints are compared as `[start, end+1 day)`; adjacent bookings are permitted. The original minimum term is three calendar months, not a fixed 90-day guess. Tenancies carry confirmed and blocked span projections. A pending original blocks only its proposed span; a pending renewal extends the blocking envelope without changing the current agreed terms. Action paths and deferred checks keep those projections consistent with the exact immutable contract rows.

`personal_access_tokens.tokenable_id` is a UUID morph association to the Laravel users model. It is not automatically a conventional PostgreSQL FK just because an ERD draws a link. Constrain the allowed model/morph type and explicitly enforce user/token integrity/deletion behavior. Browser login creates no PAT. The sessions.user_id link is nullable for guest CSRF sessions. password_reset_tokens.email is a broker lookup, not necessarily a conventional FK. Store hashes, finite expiry and approved abilities; do not expose token records through Data API grants.

Supabase Storage remains provider-managed; Laravel owns users/session/reset/PAT tables. Bootstrap the private application schema before Laravel creates migration history. No independent Prisma schema/migration owner belongs in this Laravel project.

Tenant contract confirmation/rejection actions must run in one database transaction after Laravel authentication, Policy authorization, and tenancy row locking. The trusted Laravel action sets the tenant UUID transaction-locally with `SELECT set_config('rentos.actor_id', ?, true)` immediately before writing the embedded outcome fields. The contract trigger rejects an unset or nonmatching actor; the `true` flag is required so pooled connections cannot retain identity after commit/rollback. This setting is trusted application context, not a substitute for database privilege isolation: browser/Data API roles receive no application-schema grants, and only the Laravel runtime role can execute these writes.
